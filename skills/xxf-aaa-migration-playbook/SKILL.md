# 迁移手册技能

## 适用场景

- DB 引擎切换
- 路由体系替换
- 缓存与存储迁移
- SDK 大版本升级

## 标准步骤

1. 盘点影响面
2. 设计双轨期（双写/双读/影子）
3. 灰度验证
4. 全量放开
5. 回滚与收尾

## 反模式

- 一步到位无灰度。
- 无回滚开关直接替换。
