# iOS Performance Checklist

## 1. 主线程安全

- [ ] 主线程无同步阻塞调用
- [ ] 主线程无重 I/O / 重 JSON 解析 / 重数据库查询
- [ ] 启动阶段无重资源立即初始化

## 2. UI 与渲染

- [ ] 列表复用路径无重复重对象创建
- [ ] 图片加载有降采样/缓存策略
- [ ] 无无差别 `reloadData()` 滥用
- [ ] 动画与布局更新不过度触发

## 2.1 SwiftUI 关键项

- [ ] `body` 内无排序/过滤/格式化等重计算
- [ ] `ForEach` identity 稳定且可复用
- [ ] 无顶层根视图频繁切换导致 identity churn
- [ ] 无 `GeometryReader` + 状态回写布局反馈回路
- [ ] 观察依赖面最小化（避免更新扇出）

## 3. 并发与异步

- [ ] 并发任务有上限/取消策略
- [ ] 网络请求有 timeout/退避/复用
- [ ] 无竞态引发重复计算与重复请求

## 4. 内存与缓存

- [ ] 缓存有容量上限
- [ ] 缓存有失效策略
- [ ] 无明显大对象重复分配

## 5. 验证证据

- [ ] 已执行最小构建验证
- [ ] 已执行最小相关测试（若可用）
- [ ] 已区分 Long Updates / Frequent Updates 并分别给出证据
- [ ] 已给出性能门禁结论与修复路径
