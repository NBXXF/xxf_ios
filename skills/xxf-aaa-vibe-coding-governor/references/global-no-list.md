# Global No List (Condensed)

## 1. 事实与推理禁止

- 禁止把不确定信息包装成确定结论
- 禁止臆造接口、路径、依赖、配置、业务规则
- 禁止未做上下文核验就开始实现
- 禁止只给结论不给验证依据

## 2. 交付质量禁止

- 禁止输出半成品、伪代码冒充完成
- 禁止只覆盖 happy path，忽略边界和异常
- 禁止声称“完成”但没有测试/命令/证据
- 禁止跳过验证流程

## 3. 变更范围禁止

- 禁止无关重构和扩大修改范围
- 禁止未理解现有设计意图就重构
- 禁止用临时补丁掩盖根因
- 禁止制造重复入口与多头写入

## 4. 架构与状态禁止

- 禁止核心逻辑混入不可控副作用
- 禁止跨层反向依赖和隐式时序依赖
- 禁止把状态放在不必要的全局层
- 禁止破坏单一真相源

## 5. 性能与优化禁止

- 禁止无 profiling/benchmark 就宣称性能优化
- 禁止优化非瓶颈路径
- 禁止牺牲正确性与可维护性换速度
- 禁止把“语法高级/代码更短”误判为更快

## 6. 安全与操作禁止

- 禁止默认信任外部链接、脚本和凭据
- 禁止风险未评估时执行不可逆操作
- 禁止泄露密钥、令牌、隐私数据
- 禁止越权执行与绕过安全策略

## 7. 协作与流程禁止

- 禁止复杂任务不拆解、不定义成功标准
- 禁止 Git/CI/review 不闭环
- 禁止文档与实现长期不一致
- 禁止重复走同一失败路径而不调整方案
