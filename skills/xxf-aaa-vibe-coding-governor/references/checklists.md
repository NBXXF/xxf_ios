# Vibe Coding Checklist

## 1. 任务定义清单

- [ ] 目标可观察、可验证
- [ ] 边界明确（不改项已写清）
- [ ] 验收标准可执行（命令/断言/检查项）
- [ ] 输入输出与失败语义明确
- [ ] 关键约束已记录（技术、时间、安全、兼容）

## 2. 执行前清单

- [ ] 已读 `README.md` / `AGENTS.md`
- [ ] 已定位相关代码与调用链
- [ ] 已确认测试入口与构建入口
- [ ] 已识别复用点（拼好码优先）
- [ ] 已识别高风险点（状态、并发、生命周期、数据）

## 3. 实施过程清单

- [ ] 仅做最小必要改动
- [ ] 不顺手重构无关代码
- [ ] 每步改动都有对应验证
- [ ] 异常路径与边界条件有处理
- [ ] 行为变化同步更新文档/注释

## 4. 门禁验证清单

### 代码门禁

- [ ] 编译/静态检查通过
- [ ] 核心路径测试覆盖
- [ ] 关键回归场景已验证

### 结构门禁

- [ ] 未新增重复职责入口
- [ ] 依赖方向未被破坏
- [ ] 未引入隐式全局状态耦合

### 运行门禁

- [ ] 启动/执行路径可复现
- [ ] 关键日志可定位
- [ ] 错误可观测、可诊断

### 文档门禁

- [ ] README/AGENTS/配置示例与实现一致
- [ ] 新增命令和约束已记录

## 5. 交付证据清单

- [ ] 变更摘要（行为维度）
- [ ] 验证命令与关键输出
- [ ] 风险结论（Block/Warn/Pass）
- [ ] 残余风险与影响面
- [ ] 回滚或缓释路径

## 6. 复盘沉淀清单

- [ ] 失败模式是否可转为规则
- [ ] 验收标准是否可脚本化
- [ ] 可复用流程是否可沉淀为 skill
- [ ] 禁止项是否需要加入全局禁止池
