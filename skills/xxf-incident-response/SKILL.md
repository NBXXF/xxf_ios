# 事故响应技能

## 流程

1. 事件分级（P0/P1/P2）
2. 止血优先（回滚/降级/开关）
3. 明确指挥人和沟通节奏
4. 根因分析（技术 + 流程）
5. 复盘行动项（owner + deadline）

## 输出模板

- 事件时间线
- 影响面
- 根因
- 修复与预防
- 后续追踪

## 反模式

- 只修现象，不做复盘。
- 没有行动项 owner 与截止日期。
