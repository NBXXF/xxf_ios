# 测试策略（Test Strategy）

## 触发场景

- 新模块上线前需要测试方案
- 重构后需要回归策略
- 线上问题复盘后补测试

## 策略框架

1. 单元测试：核心纯逻辑、边界输入、错误分支。
2. 集成测试：模块协作、依赖注入、接口契约。
3. 回归测试：高频路径、历史故障用例、版本兼容。
4. 故障注入：超时、空数据、错误码、并发冲突。

## 输出模板

- 测试范围（In Scope / Out of Scope）
- 风险分级（High / Medium / Low）
- 用例矩阵（模块 × 场景 × 预期）
- 自动化优先级（必须自动化 / 可手测）

## 反模式

- 只测 happy path，不测失败路径与边界。
- 仅堆数量，不关注关键风险链路覆盖率。
