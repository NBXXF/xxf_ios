# 项目规划技能

## 输出内容

- 目标与范围
- WBS 任务拆解
- 里程碑与关键路径
- 风险台账（概率/影响/应对）
- 负责人与时间表

## 推进机制

- 周节奏同步
- 风险滚动更新
- 阻塞问题升级路径

## 反模式

- 只列时间，不列依赖与风险。
- 负责人不明确，任务悬空。
