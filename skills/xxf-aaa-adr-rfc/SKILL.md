# ADR / RFC 决策技能

## 适用场景

- 技术选型（数据库、路由、缓存、日志、SDK）
- 架构重构或迁移
- 跨团队争议方案收敛

## 输出结构（强制）

1. 背景与目标
2. 备选方案与约束
3. 决策结论与权衡
4. 风险与缓解策略
5. 迁移计划与回滚条件
6. 验收指标与观察窗口

## 反模式

- 只给结论，不写 trade-off。
- 不定义回滚条件直接上线。
