# 发布管理（Release Management）

## 触发场景

- 版本提测、灰度、全量发布
- 多模块联合发布排期
- 发布后异常回滚

## 发布流程

1. 准备阶段：冻结范围、确认依赖、完成门禁。
2. 提测阶段：冒烟、回归、关键链路验证。
3. 灰度阶段：小流量观察指标与告警。
4. 全量阶段：分批放量、持续监控。
5. 复盘阶段：问题归档与改进动作。

## 关键清单

- 发布范围与负责人
- 风险点与应急联系人
- 监控指标与阈值
- 回滚触发条件与操作步骤

## 反模式

- 只发布不监控，异常后无决策阈值。
- 没有回滚演练，线上事故处理混乱。
