# xxf-aaa-risk-gate — 触发用例

## 应该触发

- "这个 PR 能不能放行"
- "帮我做风险分级"
- "哪些问题必须阻断发布"
- "这次发版需要灰度吗"

## 不应该触发

- "帮我写业务代码" → 实现请求，不是风险评估
- "某个单测怎么改" → 具体测试实现问题
- "帮我 review 这次代码哪里有 bug" → 应走 `xxf-aaa-code-reviewer`
- "帮我把相关测试跑掉" → 应走 `xxf-aaa-auto-test-orchestrator`
- "这个功能最小要测哪些" → 应走 `xxf-aaa-test-strategy`

## 边界用例

- "我知道有风险但要强上"
  - 期望：触发，并要求明确止损、灰度、回滚条件
