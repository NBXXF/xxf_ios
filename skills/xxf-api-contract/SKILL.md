# API 契约技能

## 核心目标

- 接口行为可预期
- 版本升级可兼容
- 错误码与异常语义统一

## 评审清单

1. 必填/可选字段边界
2. 默认值策略
3. 错误码与重试语义
4. 向后兼容规则
5. Mock 与真接口一致性

## 反模式

- 字段临时改名不做兼容层。
- 错误码语义漂移且无公告。
